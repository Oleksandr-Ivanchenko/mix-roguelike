
# Roguelike Arena

Браузерный roguelike с волновой системой, прогрессией персонажа и боевыми механиками.
Написан на Phaser 4 + Vite, без бэкенда — всё работает в браузере.

**Репозиторий:** https://github.com/Oleksandr-Ivanchenko/mix-roguelike

**Демо:** https://oleksandr-ivanchenko.github.io/mix-roguelike/

---

## Запуск

```
npm install
npx vite
```

Открыть http://localhost:5173

## Что реализовано

### Классы персонажей
- **Воин** — ближний бой, щит, высокая броня, рывок, мечи/топоры
- **Лучник** — дальний бой, стрелы, мана-система, луки/арбалеты
- Каждый класс видит только свои навыки на level-up

### Боевая система
- Авто-атака только когда враг в радиусе оружия
- Анимация оружия: лучник — вращение лука, воин — колющий удар мечом
- Критические удары (шанс + множитель)
- Броня (снижение входящего урона, макс 70%)
- Вампиризм (лечение от урона)
- Уклонение (шанс игнорировать удар)
- Отбрасывание, заморозка врагов, поджог (DoT)
- Пробивание снарядов насквозь
- Мультивыстрел (до 4 снарядов)
- Взрывные стрелы (AoE при попадании)
- Цепная молния (прыгает на 2 ближайших врага)
- Вихрь (AoE вокруг воина каждые 3 сек)
- Метеор (каждые 8 сек падает на случайного врага)
- Щит (временная неуязвимость)

### Ресурсы и передвижение
- HP с регенерацией
- Стамина (воин): спринт / блок / уклон, авторегенерация
- Мана (лучник): навыки, авторегенерация
- Спринт (Shift) — ×1.35–1.40 скорости
- Блок (Ctrl, только воин) — снижает получаемый урон
- Уклон (Space) — короткий дэш с i-frames 450мс

### Прогрессия
- Опыт за убийства, замедленный темп прокачки
- Level-up → выбор одного из 3 случайных навыков
- Навыки: Common / Rare / Epic / Legendary с разными весами
- Стат «Удача» улучшает шансы на редкие навыки
- Синергии: взял нужную комбинацию → автобонус
- Очки статов (str/dex/vit/int) — в разработке

### Волновая система
- 1000 убийств = волна пройдена
- После волны: ввод имени → сохранение в таблицу рекордов
- Следующая волна сложнее (×1.25 HP/урон врагов)
- Номер волны сохраняется при рестарте

### Враги
- **basic** — прямое преследование
- **fast** — фланговый заход
- **tank** — медленный, много HP
- **shooter** — держит дистанцию, стреляет, стрейфится
- **flanker** — заход под случайным углом ±45–90°
- **boss** — большой, много HP
- Мутации: elite, armored, speedy, regen (регенерация)
- Сложность растёт со временем и с каждой волной

### Магазин руд (E)
- 6 случайных улучшений за руды
- Лимит 3 покупки за визит
- Реролл за IronOre (цена удваивается каждый раз)

### Ресурсы и дроп
- Руды, монеты выпадают с врагов
- Опыт-сферы остаются на месте, подбираются при контакте, исчезают через 15 сек
- Кузница навыков (TAB) — крафт из руд

### Таблица рекордов
- Top-10 в localStorage
- Имя игрока, класс, волна, уровень, убийства, очки
- Отображается на главном экране

## Управление

| Кнопка | Действие |
|--------|----------|
| WASD | Движение |
| Shift | Спринт |
| Ctrl | Блок (воин) |
| Space | Уклон/рывок |
| E | Магазин руд |
| TAB | Кузница навыков |
| Q / F | Использовать навык из слота |
| 1 / 2 | Переключить оружие |

На мобильных устройствах: виртуальный джойстик + кнопки атаки/уклона поверх игры.

## Что стоит доработать

### Геймплей
- **Очки статов** (str/dex/vit/int) показываются, но не применяются в формулах
- **Золото** копится, тратить некуда — нужен магазин за золото
- **Game Over не сохраняет результат** — leaderboard только при прохождении волны
- **Боссы волны** — механика есть (`spawnMiniBoss`), нет явного триггера на финального босса раунда
- Нет событий между волнами (элитные комнаты, сундуки, торговцы)

### Контент
- Мало типов врагов — нужны уникальные механики
- Мало синергий, особенно для лучника
- Одна процедурная арена — нет разнообразия карты

### Технические
- Нет звука и музыки
- Спрайты врагов — заглушки (нет анимаций движения/атаки)
- Нет настроек (громкость, управление)
- Нет онлайн-рейтинга (leaderboard только локально)

### Баланс
- Конкретные значения стат-капов требуют игрового тестирования
- Масштабирование на высоких волнах может быть слишком резким
- Некоторые синергии слабее других (glass_cannon, iron_fortress)
