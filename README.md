
# roguelike-phaser

Репозиторий: [https://github.com/Oleksandr-Ivanchenko/mix-roguelike](https://github.com/Oleksandr-Ivanchenko/mix-roguelike)

Рогалик на Phaser — браузерная игра с генерацией карты, боями, прокачкой и лутом.

## Демо

[Открыть демо](https://oleksandr-ivanchenko.github.io/mix-roguelike/)

## Запуск проекта

1. Установите зависимости:
   ```
   npm install
   ```
2. Запустите сервер разработки:
   ```
   npx vite
   ```
3. Откройте [http://localhost:5173](http://localhost:5173) в браузере.

## Структура проекта

- `src/` — исходный код игры (сцены, системы, UI, утилиты)
- `assets/` — игровые ресурсы (спрайты, карты, предметы)
- `index.html`, `main.js` — точка входа

## Технологии

- [Phaser](https://phaser.io/) — игровой движок
- [Vite](https://vitejs.dev/) — сборка и запуск


## Боевая система

В игре реализована продвинутая система боя:

- Поддержка дальнего (стрельба снарядами) и ближнего (удар клинком) боя, с учетом класса игрока.
- Система перезарядки оружия, мульти-выстрелов, критических ударов, пробития, взрывных стрел и цепной молнии.
- При попадании по врагу учитываются эффекты: крит, lifesteal (вампиризм), взрыв, цепная молния, заморозка, поджог, отбрасывание.
- Для ближнего боя реализована анимация выпада и проверка попадания по врагам в секторе.
- Враги получают урон, могут быть отброшены, заморожены или подожжены, умирают с эффектами (взрыв, аура вампира, кровожажда).
- Игрок может получать урон с учетом брони, уклонения, щита.
- Система опыта, выпадения ресурсов и прогрессии после убийства врагов.

## Система сложности

- Динамически увеличивает сложность игры с течением времени.
- Каждая минута — новая волна врагов, каждая 3-я волна — элитная, каждая 5-я — мини-босс.
- Сложность влияет на параметры врагов (например, здоровье, урон).
- При наступлении новой волны выводит уведомление на экран с анимацией.


## Система опыта

- При убийстве врага появляется сфера опыта (xp orb).
- Сферы бывают обычные (зелёные) и крупные (жёлтые) — в зависимости от количества опыта.
- Сферы притягиваются к игроку, если он рядом, и исчезают при сборе.
- При сборе сферы игрок получает опыт для повышения уровня.
- Визуально сферы появляются с плавной анимацией.

## Система прогрессии

- При сборе опыта игрок повышает уровень.
- При повышении уровня открывается меню выбора навыка (из 4 случайных, с учетом класса, уровня и уникальности).
- Игрок получает очко характеристик.
- Навыки имеют редкость, могут быть уникальными или привязанными к классу.
- При получении определённых комбинаций навыков активируются синергии — особые бонусы.
- С повышением уровня увеличивается волна и ускоряется спавн врагов.
